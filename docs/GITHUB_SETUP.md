## GitHub Pages

Com `index.html` na raiz, o projeto pode ser publicado como demonstração pelo GitHub Pages. Em **Settings > Pages**, escolha **Deploy from a branch**, branch `main` e pasta `/root`.

## Perfil

Depois da publicação, fixe o repositório no perfil e adicione a URL da demonstração ao currículo e LinkedIn.
