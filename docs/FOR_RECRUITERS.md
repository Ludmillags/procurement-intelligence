# For Recruiters

This is a Procurement Analytics portfolio project focused on a real purchasing workflow rather than a generic sales dashboard.

## What it demonstrates

- translating a purchasing process into data rules;
- historical price analysis;
- supplier performance measurement;
- multicriteria decision support;
- data cleaning and validation;
- Python analytics;
- Excel automation;
- dashboard/interface design.

## Main business principle

Lowest price is not necessarily lowest purchasing risk.

The recommendation considers price, delivery reliability, lead time, quality and payment terms.
